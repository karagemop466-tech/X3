Source policy

  • Official only. NFL.com for league data; the club's own site for depth charts.
  • No secondary aggregation. If a value exists only on a betting site, it is left blank and appears on Flagged for review.
  • Reproducible. The capture and parse scripts are in the repository; the self-test fails the build if a parser silently returns nothing.
  • No market data. No odds source is used because none is official. This is the single largest gap in the project and it is stated as such throughout.
