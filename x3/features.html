Fixture context

Rest, site, kickoff and network — published facts only

Only published schedule facts

Requirement R-14 asks for a fixture-context feature set built only from published schedule facts. Rest days are computed from the official kickoff dates; the neutral-site flag and the venue name come from the week page; kickoff time and network are as published. Nothing here is a forecast, a weather model or an inferred travel burden.

Deliberately absent: roof, surface and weather. The Game Book prints them for a finished game, but no stadium-level roof/surface table or NWS forecast grid exists in this repository, so those columns are not offered (see the readiness table, R-57).
