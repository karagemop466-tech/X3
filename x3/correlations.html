Correlations

Five coefficients from official numbers, each with n, an interval and a p

Official numbers only, and every value carries its n

Requirement R-07 forbids a correlation without a published sample size, and forbids computing one from a number that is not officially sourced. Each row below names the two quantities, the official page they came from, n, a 95% interval via Fisher's z, and a two-sided p.

An undefined coefficient is never printed as zero. C-05 currently covers only 9 club-position pairs from a single game, so its interval is very wide and it is published to show the shape of the question, not to answer it. A row that cannot be estimated at all shows "undefined" rather than 0, because 0 is a number and a missing estimate is not.
