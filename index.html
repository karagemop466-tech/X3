How to use this site for a decision

  1. Check what is verified. Start with the executive summary and the verified standings / injury tracker.
  2. Check what it implies. Look at own lines, candidate strategies and the leaderboard — only gate-passing strategies belong in decisions.
  3. Check what is still unknown. Read the open decisions, the question register and the Flagged for Review page before acting. Review suggestions and pick a path before implementing changes.
