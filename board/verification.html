What the verdicts mean together

The data that exists is good

The 150-game season log reconciles to the official standings on all 32 clubs (V-02), and the Week-10 injury rows match the official report on every club re-read (V-04). That is the strongest result on this board: the transcription work in this repository holds up.

The problem is which copy is published

V-01 and V-03 are the same failure twice. One tree stores the correct 150-game log; another stores a 137-game file with 13 Week-10 games still marked SCHEDULED; and the front page presents the second one as the verified feed. Nothing needs re-transcribing — one file needs retiring. That is suggestion SG-01.

Two official surfaces can disagree

V-07: for the Week-11 Thursday game the schedule page's venue block says NRG Stadium and the Game Centre's Game Info block says Reliant Stadium, for the same fixture. Both are official. The board publishes both and picks neither, which is the only honest option.

Absence is not health

V-09 confirms the brief's Malik Willis example directly: he is not in the injury report because Miami placed him on Reserve/Injured on 11/10. V-12 shows the limit of that reasoning: the reserve capture holds no 2026 entry for Lamar Jackson or Tyler Huntley, and that absence proves nothing — because the capture is partial (V-08) and because V-10 shows listed players playing. The Baltimore claim stays unconfirmed until the club roster page is read.

How to read this board. Every number is either (a) transcribed from an official NFL page whose link is on the row, (b) arithmetic on those numbers with the formula printed beside it, or (c) marked BLOCKED / UNVERIFIED with the missing input named.
