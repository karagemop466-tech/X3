The four things a decision now turns on

  1. The reserve list is an event log, not a status roster. 7 players are listed Reserve/Injured and carry Questionable/Doubtful in the Week-10 report. Using "is listed" as "is out" would have deleted 7 players who could still have played. The rule must be "reserve date after the report date → unavailable", and even that needs the report's clock, which the league page does not publish. See Reserve list.
  2. Nothing here can be called a market edge. The repository holds zero market prices, so fair-line-vs-market residuals, closing-line value and ROI are all uncomputable. The Week-11 fair lines are published as numbers with a printed formula; the difference columns are BLOCKED with the reason.
  3. The results feed on the front page is stale by a week. 13 of 14 Week-10 games still read SCHEDULED while the official schedule page has every score. The correct scores already exist in this repository, in a different tree. See Results & luck.
  4. Six stored reads of one injury report, reconciled by nobody. Four modules keep private copies of the same Week-10 page. They agree on every designation where the keys line up, and disagree on club codes and vocabulary, which is enough for a naive diff to invent 28 availability events out of nothing. Any number quoted from "the injury report" must say which copy it came from. See Injuries & depth.

What this board deliberately does not do

  • It does not publish a betting recommendation, a stake, a reward, or a leaderboard rank. There is no price data, so no return can be computed; ranking without prices would be ranking luck.
  • It does not fill a blank with an estimate. Where the official page is silent, the cell says so and the row points at Flagged for review.
  • It does not overwrite another module. It re-reads them, links them, and records the disagreement. The repo has many trees; the inventory and the conflicts are on Requirements and Flagged.

How to read this board. Every number is either (a) transcribed from an official NFL page whose link is on the row, (b) arithmetic on those numbers with the formula printed beside it, or (c) marked BLOCKED / UNVERIFIED with the missing input named. Nothing is estimated, interpolated or inferred. Where two official pages disagree, both are linked and the row is flagged on Flagged for review.
