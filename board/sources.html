Method, in one paragraph

Each official page was retrieved and read as text. Row-level values were transcribed only where the page prints them; every table on this board is generated from a stored CSV by scripts/board_build.py, so a number on a page can always be traced to a row in a file and from that row to a source link. Where two official pages disagree, both are published. Where a page had not been published, the row says so. Where a value could not be confirmed, the cell is blank, carries BLOCKED or UNVERIFIED, and appears on Flagged for review.

What is deliberately absent

  • No sportsbook, odds aggregator or third-party statistics site is cited. A price from a commercial book is not an official NFL publication, and this board does not launder one into an official-looking column.
  • No inferred value is presented as sourced anywhere on the site.
  • No figure is carried over from another tree without being re-read on this pass.

How to read this board. Every number is either (a) transcribed from an official NFL page whose link is on the row, (b) arithmetic on those numbers with the formula printed beside it, or (c) marked BLOCKED / UNVERIFIED with the missing input named. Nothing is estimated, interpolated or inferred. Where two official pages disagree, both are linked and the row is flagged on Flagged for review.

Research workspace. No betting advice, no market-price feed, no wagering of any kind. Built from board/data/*.csv by scripts/board_build.py; gated by scripts/board_verify.py.
