The dependency order

  1. Q2 (prices) blocks every return, staking score, residual and reward.
  2. Q1 (rights) blocks the private data layer and therefore every capture that is not derived analysis.
  3. Q3 (roster status) blocks any availability feature that is not a guess.
  4. Q9 (designation clock) blocks the surprise signal, which is the only injury feature the brief actually wants.
  5. Q6 + Q7 (holdout, multiplicity) block the first published leaderboard, because without them the ranking is a coin flip with a confidence interval drawn too narrow.

How to read this board. Every number is either (a) transcribed from an official NFL page whose link is on the row, (b) arithmetic on those numbers with the formula printed beside it, or (c) marked BLOCKED / UNVERIFIED with the missing input named.
