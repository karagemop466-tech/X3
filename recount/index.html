7. Method and limits

  • Transcription: all 8 chunks of the official page were read and each row was written to data/recount/reg10_2026_live_transcription.psv. The build writes data/recount/reg10_2026_live.csv and the hashes in data/recount/MANIFEST.json.
  • Raw HTML bytes were not retained: the sandbox cannot reach nfl.com with curl (TLS failure). The agency capture of 2026-11-15 is an independent earlier reading of the same page; it agrees with this transcription on every player.
  • Row counts per game equal the club-section counts on the page. The page prints no row totals, so the totals are computed.
  • Checks: python3 scripts/recount_verify.py.
