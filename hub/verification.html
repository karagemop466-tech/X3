Recomputed on every build: run python3 tools/build_hub.py and these numbers change with the file. Nothing here is hand-typed.

Reproduce it

python3 tools/x3_engine.py      # data -> hub/data/*.json
python3 tools/build_hub.py      # json -> hub/*.html + root index.html
python3 tools/verify_hub.py     # row-source + link gate (CI runs this)

External pages are not re-fetched by the checks: they are read once, transcribed into data/hub/*.csv, and from then on the build is deterministic and offline-verifiable. That is deliberate - a table that changes when a source page changes cannot be reviewed.

Generated by tools/build_hub.py from hub/data/*.json and data/hub/*.csv. Rows are read from official NFL.com and NFL club pages on 2026-11-14; values with no official source are left blank and flagged. Model output is labelled DERIVED and is a calculation, not a prediction of results. This site places no bets and pays no rewards.
