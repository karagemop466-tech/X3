Leaderboard and rewards

A competition structure with an empty table. Nothing may be promoted, and no reward is payable, until every blocking gate on the validation page is passed - which is why the standings below are deliberately blank.

Scoring model

  • primary: median closing-line value per bet, with a bootstrap 95% interval clustered by game-week
  • secondary: ROI at the stated vig, same interval treatment
  • qualification: DSR > 0 (SRC-10) and PBO < 0.5 (SRC-11) on the grid that was actually searched
  • display: never rank on a bare point estimate; an entry with an interval that spans zero is shown as undetermined

Categories

Single - spread, Single - moneyline, Single - total, Player prop, Prop combo (same game), Parlay (cross-game)

Season structure

  1. Registration window (spec + hash committed)
  2. Freeze (no parameter edits while grading)
  3. Grading on untouched games only
  4. Review: promote, park or ban with reasons published

Anti-gaming rules

  • One leaderboard entry per spec; a variant that changes a parameter is a new entry and increases the trial count used in DSR
  • Disclose every variant tried, including discarded ones
  • No near-duplicate entries (same family, same construction, different threshold)
  • Retire an entry that misses its own stated threshold after the review period, publicly
