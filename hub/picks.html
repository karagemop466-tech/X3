The order is the point

Side first, because it is the market the verified data says least about wrongly: the rating beats predict-zero out of sample, so the side is the only number on this board with evidence behind it. Total second, because on the backtest the model total is exactly as good as a constant - it beats nothing. Moneyline last, because it is a monotone function of the side through Phi(-spread / sigma): it cannot disagree with the spread, so it adds no independent information. Publishing it last is a statement about what it is worth.
