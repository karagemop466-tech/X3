How to read every table

  • VERIFIED VERIFIED - transcribed from an official NFL.com page, with the link in the row.
  • DERIVED DERIVED - arithmetic over verified rows; the inputs and the formula are printed so you can recompute it.
  • ASSUMPTION ASSUMPTION - a parameter someone chose. It is a model setting, never a fact.
  • UNVERIFIED - blank cell. Nothing was inferred to fill it.
