Q44/Q45 — play rate and inactive rate per designation

Play rate = share of designated players with an official playtime row (>0 snaps) in that game's Game Book. Inactive rate = share found in the game's Not Active section, computed only for games whose Game Book render carries an explicit Not Active section (rule A); games whose render drops those labels are excluded from this metric (rule B) rather than guessing. Intervals are Wilson score 95%.

How to read this

  • Denominators count only resolved rows; unresolved rows and rule-B exclusions are shown as columns, never folded into the rate.
  • UNRESOLVED happens when a name cannot be matched with confidence (position families, duplicate keys, missing render bands) — those rows sit on the Player join page with reasons.
  • This is a descriptive pilot: three seasons, twelve games, convenience sample. It is pre-registered as measurement only — no model consumes it in this pass.
