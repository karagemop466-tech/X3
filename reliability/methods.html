Methods (pre-registered before capture)

  1. Sample. Week 10 of 2023, 2024, 2025. The first four games as listed on each official report page. Convenience sample — disclosed on every page. 2026 Week 10 excluded (other session's claim + game not final at capture time).
  2. Archive (Q43). Report chunks 0–1 stored verbatim with source URL and fetch time; sha256 of every stored file in reliability/manifest.csv.
  3. Designations. Rows whose Game Status is Out, Doubtful or Questionable. Blank-status rows are not part of this join (a no-designation baseline needs full playtime capture — next increment).
  4. Outcome — played. A row in the game's official Playtime Percentage section with ≥1 snap, matched by first-initial + surname + position family, game-scoped. Duplicate keys resolve by row count; fewer playtime rows than report rows is UNRESOLVED. Missing render bands make absence UNRESOLVED.
  5. Outcome — inactive. Presence in the game's parsed Not Active set, only when the Game Book render carries an explicit Not Active section (rule A). Games whose render drops the labels (rule B: IND@NE 2023, DEN@KC 2024, ATL@IND 2025) are excluded from the inactive rate entirely.
  6. Conflicts. Listed Not Active yet has a playtime row → CONFLICT, excluded from both rates, published on the join and flagged pages.
  7. Rates. Wilson score 95% intervals. Denominators exclude unresolved/excluded rows; the excluded counts are columns on the Reliability page. Per-season n published on every row.
  8. Reproducibility. python3 scripts/reliability_build.py regenerates every CSV and page deterministically; python3 scripts/reliability_verify.py re-parses the raw captures, re-checks completeness, evidence tokens and rate arithmetic.

What this module deliberately does not do

  • No inference: unresolved stays unresolved; no value is filled from expectation.
  • No model input: these are descriptive measurements; no strategy consumes them in this pass.
  • No non-official source: every table row links to nfl.com or static.www.nfl.com.
  • No shared-file edits: landing navigation registration for reliability/ is logged as an integration request in COORDINATION.md, not done here.
Every table row on this module links to its official source or is explicitly flagged. Rates are descriptive measurements of the sample described on the Methods page — not a model input, not advice.
