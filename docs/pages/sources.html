Verification policy

  • Every data row on this site carries a source link to an official or official-hosted source.
  • If a value cannot be confirmed from such a source, the cell is left blank and marked UNVERIFIED. Values are never inferred.
  • Source tiers are explicit: Official (the league, publisher, or competition host) · Academic (journal/SSRN/university repository) · Trusted-secondary (community data projects and replications) · Industry-secondary (practitioner press — flagged).
  • Conflicts between sources are published on the Flagged page, never resolved by guessing.

Method notes

  • Injury rows were transcribed from the official page in 8 fetched chunks on 2026-11-14 and are stored canonically in docs/data/injury-2026-week10.csv; the per-team and per-game tables are generated from that file by tools/build_data_pages.py (no hand-keyed duplicates).
  • Standings were cross-checked team-by-team against the injury page's record headers — all 28 non-bye teams matched.
  • Derived values (e.g., Out/Doubtful/Questionable counts) are computed from the verified rows and link back to the same official source.
  • An automated check (tools/verify_site.py) confirms every table row on the site carries either a source link or an UNVERIFIED marker.
