How this board works (change control)

  1. Anyone reviews a proposal and sets its status: Accepted / Rejected / Needs changes.
  2. Accepted proposals are implemented in a later change with their own verification pass.
  3. Rejected proposals stay on the record with the reason — nothing is silently dropped.
  4. Each row states impact, effort, risk, and what it depends on, so the best path can be chosen with eyes open.
