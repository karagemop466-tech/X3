Estimation pipeline (produces the values in a later run)

  1. Data: nflverse play-by-play + weekly rosters + player stats (github.com/nflverse); official cross-check vs nfl.com/stats.
  2. Unit: game × player × market leg. EV work additionally needs closing consensus lines — data gap Q-07.
  3. Estimation: contingency tables (binary legs) / rank-copula (continuous props); game-level block bootstrap (10,000) for CIs.
  4. Publication rule: value + CI + sample size + data version hash; any pair whose CI spans 0 is displayed blank.
  5. Refresh: re-estimate each offseason; freeze within-season (Gate G8).
