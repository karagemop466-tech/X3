# Origin module — line origination for the X3 NFL project

Session `arena/f2df8317-x3`. This module implements the eight new requirements of the
project brief. It is self-contained: its pages are generated by `scripts/origin_build.py`
from frozen inputs, and every claim carries a source link or an explicit flag.

## The eight requirements → where they live

| # | Requirement | Data | Page |
|---|-------------|------|------|
| R1 | Price-snapshot store (open + close for every market we originate) | `data/snapshots.json` | snapshots.html |
| R2 | Verified results feed (makes backtests possible at all) | `data/results.json` | results.html |
| R3 | Originate side first, then total, then moneyline | `data/markets.json` | markets.html |
| R4 | Fair line / market line / difference as separate columns | `data/markets.json` | markets.html |
| R5 | Signal separated from staking in the leaderboard | `data/leaderboard.json` | leaderboard.html |
| R6 | Track the depth of the replacement (ordinal), not just the fact | `data/depth.json` | depth.html |
| R7 | Correlations only from officially sourced numbers, n published | `data/correlations.json` | correlations.html |
| R8 | Demotion gate (live → paper) | `data/gates.json` | gates.html |

## Data flow

```
official NFL.com week pages ──(CI capture: scripts/origin_capture.py)──▶ data/results.json
                                                                       (163/163 cross-checked
                                                                        vs data/desk/games.json)
hub/data/lines.json (X3-v1 fair sides + totals, preregistered) ──▶ data/markets.json
moneyline derived from side via P(home win)=Φ(margin/13.5)      ──▶ data/markets.json
hub/data/injuries.json × data/desk/depth.json                   ──▶ data/depth.json
results feed (walk-forward)                                     ──▶ data/backtest.json
official numbers only                                           ──▶ data/correlations.json
all of the above                                                ──▶ origin/*.html
```

## Commands

```
python3 scripts/origin_capture.py results   # CI: fetch official pages → data/results.json
python3 scripts/origin_capture.py close     # cycle-close marker (run pre-kickoff)
python3 scripts/origin_build.py             # rebuild all data/*.json + *.html (deterministic)
python3 scripts/origin_verify.py            # verify everything; exit 1 on any failure
```

## Honest-state note

Backtests are computable now (the results feed exists). ROI is not: **no official source
publishes NFL market prices**, so market-line, difference, CLV and ROI cells stay blank and
flagged rather than invented. The snapshot store, leaderboard and gates already reserve those
columns — connecting a price source (owner decision Q-A01) activates them with no schema change.
