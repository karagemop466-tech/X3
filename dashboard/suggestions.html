How to use this page

  • Pick a row. Read the three options and the recommendation.
  • Change the status to Adopted when a path is chosen, Deferred when it is knowingly postponed. Nothing is implemented on Proposed.
  • Anything marked Adopted only takes effect when the matching change is committed. The two adopted items on this page are already reflected in the pipeline.
Verification rule: a row is verified only when its value was read from an official NFL source and the row carries that source's link. Values that could not be confirmed are blank and marked UNVERIFIED; they are repeated on the Flagged for Review page. Model output is always labelled DERIVED and is never presented as fact.
