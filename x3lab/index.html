What this site is

A decision-support dashboard for originating NFL lines and building selectively skill-based betting strategies. Every table row links to an official or trusted source. Values that cannot be confirmed are left blank and flagged — never filled in. Model output is labeled as model output, assumptions are labeled as assumptions.
