# NFL Decision Lab

A source-first framework for building and evaluating NFL betting signals. The site separates verified facts, methods to test, and missing information; it does **not** publish live lines, picks, injury assertions, or performance claims without verified data.

## Run locally

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Project status

The repository began with no NFL datasets or application. Live NFL odds, dated official injury reports, historical closing lines, play-by-play inputs, and validated strategy results are not present. Missing values are intentionally blank and clearly flagged, not inferred. See [Flagged for Review](flagged.html) and [Sources & methods](sources.html).

The site is static and ready for GitHub Pages deployment via `.github/workflows/pages.yml` when Pages is enabled for the repository.
