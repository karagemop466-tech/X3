# X3 &mdash; NFL Decision Intelligence

Originate NFL lines, generate and validate betting signals, track injuries and depth-chart deficiencies, and review improvement suggestions before any change is implemented.

## Site
GitHub Pages site: landing page + category subpages (Executive Summary, Suggestions & Review, Flagged for Review, Strategies & Signals, Injuries & Depth, Sources). Every table row carries a source link to an official site; unverified values are left blank and flagged. Nothing is inferred.

## Verification standard
- Every table row must have a source link to an official site.
- If a value cannot be confirmed from an official source, leave it blank and flag it unverified.
- Never infer or fill in values.
