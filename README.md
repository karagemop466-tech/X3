# Fourth Down — NFL Decision Lab

A static, evidence-first NFL research dashboard: executive overview, decision questions, candidate signal hypotheses, validation gates, correlation/parlay methodology, lineup and injury data requirements, leaderboard design, official reference links, and a clearly labeled **Flagged for review** section.

## Run locally

Open `index.html`, or serve the repository root with any static HTTP server. There is no build step, package install, backend, data feed, betting recommendation, or fabricated performance record.

## Publish with GitHub Pages

In the repository's GitHub settings, set **Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`. Once deployed, `index.html` is the landing page. This repo has no automated deployment workflow; a live Pages deployment cannot be claimed until enabled and confirmed in GitHub.

## Evidence and limitations

The dashboard started with no application, source datasets, odds, injury feed, or strategy results. Official NFL links are provided for source review and data schema planning; links do not certify any live page value or constitute an imported dataset. Blank fields are intentional. Proposed models and gates are research methodology, not claims of predictive performance. See the on-site **Flagged for review** section and [`COORDINATION.md`](COORDINATION.md).
