The repository carries 27 separate site trees built by earlier sessions for the same brief. Nothing was deleted. This page records what each contains so a reader can tell which module is maintained and which is history.

This table is a live scan of the repository, taken when the module was last built. The main finding. 27 separate trees publish different numbers for the same fact. That is not a bug in any one of them; it is what happens when many sessions answer the same brief independently. Until one tree is chosen as canonical and the rest are labelled archive, any number quoted "from the site" is ambiguous.
