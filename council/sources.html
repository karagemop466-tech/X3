Sources

Every page and file this tree draws on, split into official NFL sources and repository artifacts, with the retrieval status of each.

Two kinds of source are listed, and they are not equivalent. Official means an NFL-operated page that was read directly on 2026-11-14. Repository artifact means a file in this repository that holds a transcription or a model output; it is DERIVED and is badged that way on every row that uses it. A transcription is only as good as the page it came from, which is why the capture manifest is linked.

Why no betting source is listed

No NFL or club page publishes spreads, totals, moneylines, prop prices or closing numbers. Several commercial and media sites publish them, and none of them is an official source, so none is used. The market columns on this site are blank for that reason. Filling them from a non-official source would be worse than leaving them blank, because a wrong price produces a confident wrong edge. See S01.
