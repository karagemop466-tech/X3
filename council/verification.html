C-01 - the defect, stated plainly

data/desk/correlations.json publishes r = -0.161, n = 137 labelled game total vs |margin|, with the reading "same-game total and blowout size move together".

  • Recomputed on the same 137 finals: r(total, |margin|) = -0.0157.
  • Also recomputed: r(total, signed home margin) = -0.1607. That is the published number.
  • So the published value is the signed-margin statistic published under an absolute-margin label. The pipeline is fine; the label is wrong.
  • The reading is a sign error as well: a negative r means the two quantities move in opposite directions, not together.
  • Its 95% interval contains 0 either way, so even correctly labelled it is not distinguishable from no relationship and should not be used as a parlay leg screen.

The file belongs to another session, so it is not edited here. The fix is S08, and it is recorded as flag C-01.
