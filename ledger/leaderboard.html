Leaderboard and demotion gate

Ranking uses the signal track only. Staking results are shown beside the signal, never inside the rank, so a lucky staking run cannot hide a weak signal. A strategy is ranked only if every gate passes; otherwise it shows NOT RANKED with the failing gate named.
